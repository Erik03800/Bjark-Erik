Variablen und Datentypen

Eine Variable ist ein benannter Speicherplatz. Sie hat einen Datentyp, der festlegt, welche Werte hineinpassen und was man damit rechnen darf.

name = "Mia"        # str (Text)
alter = 17          # int (ganze Zahl)
groesse = 1.68      # float (Kommazahl)
volljaehrig = False # bool (Wahrheitswert)
String name = "Mia";       // Text
int alter = 17;            // ganze Zahl
double groesse = 1.68;     // Kommazahl
boolean volljaehrig = false; // Wahrheitswert
Achtung bei der Division: In Java ist 7 / 2 gleich 3 (ganzzahlig), in Python ist 7 / 2 gleich 3.5. Den Rest liefert 7 % 2 (Modulo) = 1.

Bedingungen (if / else)

Mit einer Bedingung entscheidet das Programm, welcher Code läuft. Die Bedingung ist ein Ausdruck, der wahr oder falsch ergibt. Es wird immer nur der erste passende Zweig ausgeführt.

if alter >= 18:
    print("volljährig")
else:
    print("minderjährig")
if (alter >= 18) {
    System.out.println("volljährig");
} else {
    System.out.println("minderjährig");
}

Schleifen


Eine Schleife wiederholt Code. Die for-Schleife nimmst du, wenn du die Anzahl der Durchläufe kennst. Die while-Schleife läuft, solange eine Bedingung wahr ist.


for i in range(1, 6):    # 1, 2, 3, 4, 5
    print(i * i)

summe = 0
while summe < 100:
    summe += 10


for (int i = 1; i <= 5; i++) {
    System.out.println(i * i);
}

int summe = 0;
while (summe < 100) {
    summe += 10;
}

Funktionen und Methoden


Eine Funktion bündelt Code unter einem Namen. Sie bekommt Parameter und gibt mit return einen Wert zurück. So schreibst du Code einmal und nutzt ihn oft.


def ist_gerade(zahl):
    return zahl % 2 == 0

print(ist_gerade(8))   # True


static boolean istGerade(int zahl) {
    return zahl % 2 == 0;
}

System.out.println(istGerade(8));   // true







Listen und Arrays


Mehrere Werte lassen sich in einer Liste (Python) bzw. einem Array (Java) speichern. Der Zugriff läuft über den Index, und der beginnt bei 0.


noten = [12, 9, 14, 7]
print(noten[0])        # 12
noten.append(10)
summe = 0
for n in noten:
    summe += n
print(summe / len(noten))


int[] noten = {12, 9, 14, 7};
System.out.println(noten[0]);   // 12
int summe = 0;
for (int n : noten) {
    summe += n;
}
System.out.println((double) summe / noten.length);


Ein Java-Array hat eine feste Länge. Für wachsende Listen nutzt man ArrayList.
